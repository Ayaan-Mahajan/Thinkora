# Thinkora
Think deeper. Decide better.

Thinkora is a CLI-based decision companion built with Python that helps users make thoughtful decisions through structured evaluation and reflection.

Instead of simply recommending an option, Thinkora remembers how your thinking evolves over time.

## Features
- Add and save decisions with multiple options
- View all saved decisions
- Evaluate decisions using weighted criteria
- Generate personalized recommendations
- Save evaluation history with timestamps
- Re-evaluate the same decision multiple times
- View past recommendations and scores
- Track how your priorities change over time
- Mark and save your final choice
- Display how many times a decision has been evaluated
- Handle invalid inputs gracefully

## Why Thinkora?
Most people make important decisions mentally and forget why they chose a particular path.

Thinkora aims to become a personal decision companion — helping users think more clearly, document their reasoning, and learn from the choices they make over time.

Thinkora isn't just about answering:
"What should I choose?"

It's about understanding:
"How did I make this decision, and how did my thinking change over time?"
