# Thinkora
Think deeper. Decide better.

Thinkora is a Python CLI application that helps users capture and organize important decisions in a structured way.

## Features
- Add decisions with title, deadline, and importance level
- Add multiple options for each decision
- Save decisions using JSON
- View previously saved decisions
- Data persists even after restarting the application

## Built With
- Python
- JSON
- Git & Github

## Future Plans
- Weighted decision criteria
- Decision scoring system
- Reflection notes
- GUI version
- Web application

## Why Thinkora?
Most people make important decisions mentally and forget why they chose a particular path.

Thinkora aims to become a personal decision companion — helping users think more clearly, document their reasoning, and learn from the choices they make over time.
